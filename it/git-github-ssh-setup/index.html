    问题原因解决方案
    Permission denied (publickey)公钥未添加或添加错误检查 GitHub 上的公钥是否正确
    Host key verification failed服务器指纹未信任删除 ~/.ssh/known_hosts 中的条目
    Connection timed out网络问题或防火墙检查网络连接和防火墙设置
