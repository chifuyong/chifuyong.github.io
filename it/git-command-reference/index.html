    基本操作命令

    版本管理

    • git init：初始化仓库
    • git status：查看工作区、暂存区状态
    • git add [file name]：将工作区的文件（新建或修改）添加到暂存区，git add . 表示添加所有修改过的文件到暂存区
    • git commit -m "commit message" [file name]：将暂存区的文件提交到本地库，-m 表示此次提交的修改概述

    查看历史

    • git log：查看 commit 的详细历史记录，其他常用命令参数如下：

    三者区别如下图：

    比较差异

    • git diff [file name]：比较工作区中文件和暂存区差别
    • git diff [版本号] [file name]：工作区文件和本地库历史版本比较

    版本回退

    • git reset：版本回退/前进，有三种方式，参数作用如下：

    git reset --hard [局部版本索引] 可直接恢复到相应版本，git reset --hard HEAD^ 表示回退到上个版本（多少个 ^ 代表回退多少个版本），git reset --hard HEAD~n 表示后退 n 步。

    分支管理命令

    命令说明
    git branch -v查看全部分支
    git branch [branch name]创建分支
    git branch -d [branch name]删除分支
    git checkout [branch name]切换分支
    git merge [branch name]把指定分支合并到当前分支
    git rebase [branch name]变基合并，保持线性历史
      gitGraph
    commit id: "init"
    branch develop
    checkout develop
    commit id: "feat-1"
    checkout main
    commit id: "hotfix"
    checkout develop
    commit id: "feat-2"
    checkout main
    merge develop

    git rebase 与 merge 的区别：rebase 会把 commit 内容暂存起来然后再合并，合并后不会导致分叉，保持线性历史。

    暂存操作命令

    命令说明
    git stash save "info"暂存当前工作区和暂存区内容
    git stash list显示暂存过的所有列表
    git stash pop恢复最新暂存数据并删除记录
    git stash apply恢复暂存数据但保留记录
    git stash drop stash@{X}删除指定暂存记录
    git stash clear删除所有暂存记录

    开发时在需要排查其他分支的 bug 问题时常用。

    远程相关命令

    命令说明
    git remote -v查看当前所有远程地址别名
    git remote add [origin] [url]添加远程服务器关联地址
    git remote remove [origin]删除远程关联地址
    git clone [url]克隆远程仓库代码
    git fetch更新本地的远程跟踪分支
    git pull相当于 fetch + merge
    git push [alias] [branch]推送代码到远程服务器
      sequenceDiagram
    participant L as 本地仓库
    participant R as 远程仓库
    L->>R: git push
    R-->>L: 推送成功
    R->>L: git fetch
    L->>L: git merge
    R->>L: git pull (= fetch + merge)

    git clone：克隆远程服务器仓库代码（默认拉取 master 分支），加上 -b [branch name] 参数可以拉取指定分支。

    git pull：相当于 fetch + merge，先更新远程跟踪分支（例如 origin/master），再合并到本地分支，有冲突需要解决冲突。

    git push：推送代码到远程服务器，有冲突需要 pull 解决代码冲突后再 push 到远程服务器。
