    函数说明
    COUNT()统计指定列不为 NULL 的记录行数
    MAX()计算指定列的最大值；若为字符串类型则按字符串排序运算
    MIN()计算指定列的最小值；若为字符串类型则按字符串排序运算
    SUM()计算指定列的数值和；若指定列类型不是数值类型，则计算结果为 0
    AVG()计算指定列的平均值；若指定列类型不是数值类型，则计算结果为 0

    四、数据的完整性

    作用：保证用户输入的数据保存到数据库中是正确的。

    确保数据的完整性 = 在创建表时给表中添加约束。

    1. 实体完整性

    • a. 主键约束（PRIMARY KEY）

    • b. 唯一约束（UNIQUE）

    特点：数据不能重复。

    • c. 自动增长列（AUTO_INCREMENT）

    给主键添加自动增长的数值，列只能是整数类型。

    2. 域完整性

    • a. 数据类型：（数值类型、日期类型、字符串类型）

    • b. 非空约束：NOT NULL

    • c. 默认值约束：DEFAULT

    3. 引用完整性

    • a. 外键约束：FOREIGN KEY

    五、多表查询

    多表查询有如下几种：

    1. 合并结果集

    作用：合并结果集就是把两个 SELECT 语句的查询结果合并到一起！

    2. 连接查询（非常重要）

    连接查询就是求出多个表的乘积，例如 t1 连接 t2，那么查询出的结果就是 t1*t2。

    连接查询会产生笛卡尔积，假设集合 A={a,b}，集合 B={0,1,2}，则两个集合的笛卡尔积为 {(a,0),(a,1),(a,2),(b,0),(b,1),(b,2)}。可以扩展到多个集合的情况。

    还可以为表指定别名，然后在引用列时使用别名即可。

    六、MySQL 数据备份与恢复

    在控制台使用 mysqldump 命令可以用来生成指定数据库的脚本文本。注意：脚本文本中只包含数据库的内容，而不会存在创建数据库的语句！所以在恢复数据时，还需要手动创建一个数据库之后再去恢复数据。

    注意：在执行脚本时需要先行核查当前数据库中的表是否与脚本文件中的语句有冲突！例如在脚本文件中存在 CREATE TABLE a 的语句，而当前数据库中已经存在了 a 表，那么就会出错！
