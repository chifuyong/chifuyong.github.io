    二. Hadoop 安装

    Hadoop 是基于 Java 平台实现的，首先需要有 JDK 环境，然后再去搭建 Hadoop 集群，需要做如下配置：

    1. 配置 JDK
    2. 下载安装 Hadoop
    3. 修改 Hadoop 集群配置文件
    4. scp 同步每台机器的 Hadoop 环境变量配置和软件目录
    5. 初始化 Hadoop 的 NameNode
    6. 启动 Hadoop
    7. 验证 Hadoop

    三. 时间同步

    如果服务器可以连接互联网且本身会自动同步时间，则可以不用配置。但是如果是内网无法连接互联网或者无法同步时间的时候，则需要配置下 hadoop01-04 这几台服务器之间的时间同步，否则时间久了就会导致时间偏差，导致集群执行任务时时间不同步。尤其是如果后面还需要部署 HBase 的话，时间同步是必须要做的，否则一旦时间出现误差，将会出现大问题。

    首先先设置好 hadoop01-04 所有机器的时区：timedatectl set-timezone Asia/Shanghai

    可以连接互联网时的配置

    可以连接互联网，但是服务器默认没有去同步时间时，可以先 yum 安装 ntpd 服务，然后配置所有机器与互联网上的时间服务器进行时间同步。

    四. 常见问题排查

    问题 1：NameNode 无法启动

    现象： 执行 start-dfs.sh 后，jps 只显示 DataNode，没有 NameNode。

    排查步骤：

    1. 检查日志文件 ${HADOOP_HOME}/logs/hadoop-*-namenode-*.log
    2. 常见原因：data_file 目录下存在旧的 current 目录，说明之前 format 过。删除所有节点的 data_file 目录后重新 format：
    1. 检查 hadoop-env.sh 中 JAVA_HOME 路径是否正确

    问题 2：节点之间 SSH 无法免密登陆

    现象： scp 拷贝文件时仍需输入密码。

    排查步骤：

    问题 3：DataNode 启动后立即退出

    现象： jps 显示 DataNode 短暂出现后消失。

    排查步骤：

    1. 检查 data_file 目录的 VERSION 文件中的 clusterID 是否与 NameNode 的一致
    2. 不一致时，删除所有节点的 data_file 目录，重新 format NameNode，再启动所有节点

    问题 4：YARN 页面无法访问

    现象： 访问 http://hadoop03:8088/ 无响应。

    排查步骤：

    1. 确认 yarn-site.xml 中 yarn.resourcemanager.hostname 配置为 hadoop03
    2. 检查 ResourceManager 进程是否在运行：jps | grep ResourceManager
    3. 检查防火墙是否已关闭：systemctl status firewalld

    问题 5：systemctl 命令报错 command not found

    现象： 在 CentOS 6 或精简版系统中，systemctl 命令不存在。
