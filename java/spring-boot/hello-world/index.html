    SpringBoot 入门案例

    chify2019-12-152022-04-29

    SpringBoot 优势

    SpringBoot 是 Spring 家族下的一个新框架，其秉承了约定大于配置的理念，避免了以往开发 Spring 应用中的各种复杂 xml 配置，其优势如下：

    • 简化了 Spring 应用的搭建和开发，提高了生产力，缩短了开发时间。
    • 嵌入式的 Tomcat、Jetty，不再需要使用 war 的方式去部署。
    • 使用约定好的 starter 来配置 pom.xml 文件，使 Maven 配置起来更加简单。
    • SpringBoot 会自动管理各个所需开源框架 jar 包的版本，不需要自己去调整配置。
    • 整合了大量流行的开源框架，方便使用，也为 SpringCloud 奠定了基础。

    总而言之，SpringBoot 的关键点就是约定大于配置，配置、开发、部署都比以往更简单了，可以快速地开发出一个基于 Spring 的 Web 应用。

    注意：SpringBoot 不是对 Spring 的增强，而是让我们能够进行快速的 Spring 应用开发。

    3. 编写启动类

    SpringBoot 启动类（Application）上必须添加 @SpringBootApplication 注解，说明这是一个 SpringBoot 应用，是 SpringBoot 的主配置类，运行这个类的 main 方法便可启动 SpringBoot 应用。

    4. @SpringBootApplication 注解

    @SpringBootApplication 是 SpringBoot 的核心注解，它实际上是一个组合注解，包含了以下三个关键注解：

    • @SpringBootConfiguration：等价于 @Configuration，标识当前类是一个配置类，Spring 容器会通过 CGLIB 代理来管理 Bean。
    • @EnableAutoConfiguration：开启自动配置功能，SpringBoot 会根据 classpath 中的依赖自动推断并配置所需的 Bean。例如引入了 spring-boot-starter-web，SpringBoot 就会自动配置 Tomcat、Spring MVC 等。
    • @ComponentScan：自动扫描当前包及子包下所有标注了 @Component、@Service、@Repository、@Controller 的类，将其注册为 Spring Bean。

    正是这三个注解的协同工作，才使得 SpringBoot 能做到”零配置”启动。
