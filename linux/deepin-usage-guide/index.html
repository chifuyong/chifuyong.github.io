    Deepin 使用简记

    chify2019-08-042022-04-28

    一、系统预装、应用商店软件

    以下软件都可以在应用商城中下载安装，简单快捷，省得折腾：

    类别软件说明
    浏览器Chrome内置，支持同步 Google 服务
    浏览器FireFox开源浏览器
    音乐网易云音乐Deepin 深度定制版
    办公WPS内置，兼容 Office 格式
    通讯微信（Wine）Wine 移植版
    通讯TIM（Wine）Wine 移植版
    邮件雷鸟邮件Thunderbird 邮件客户端
    网盘百度云（Linux 版）官方 Linux 版
    编辑器gedit文本编辑器
    SSH 工具electerm支持 SSH、SFTP
    思维导图Xmind ZEN思维导图工具
    画图KolourPaint轻量画图工具
    编辑器GvimVim 图形化版本

    二、常用软件、开发工具安装

    • JDK、Eclipse

    JDK、Eclipse 安装与配置 点击这里

    • electron-ssr

      一直喜欢用这款软件，使用方便简单，搭完梯子才好同步 Chrome 书签。。。

      GitHub 下载地址

    • FinalShell

      Xshell 和 Xftp 的替代品，其实 ssh 命令已经挺好用的了，就是感觉还想要一款 Xftp 类似的软件，这款国内人做的软件不错，就是界面稍微丑了点，其他还好，就算是代替 Xftp 的吧。

      下载地址

    • PostMan

      tar.gz 解压版，需要手动配置启动图标。

      官网下载地址

    • Typora

      tar.gz 解压版，需要手动配置启动图标。

      官网下载地址

    • IntelliJ IDEA

      tar.gz 解压版，需要手动配置启动图标。

      官网下载地址

    • Navicat

      tar.gz 解压版，需要 Wine 下才能运行，Deepin 发行版可直接运行，需要手动配置启动图标。

      注：试用到期可删除 /home/guan/.navicat64/

      官网下载地址

    • WinFonts（解决缺失字体问题）

      将 Windows 系统 C:\Windows\Fonts 目录下所有字体文件复制进新创建的 WinFonts 文件夹里。将 WinFonts 移到 Deepin 的 /usr/share/fonts 目录下即可。

    • JD-GUI

      官网下载 deb 包，使用 sudo dpkg -i 命令安装。

      官网下载地址

    • TeamViewer

      官网下载 deb 包，使用 sudo dpkg -i 命令安装。会缺失：qml-module-qtquick-dialogs (>= 5.5) 和 qt56-teamviewer 依赖。

      官网下载地址

    • Xmind

      官网下载 deb 包，使用 sudo dpkg -i 命令安装。

      官网下载地址

    • PyCharm

      Python 开发环境（JetBrains 官网下载即可）

    • WebStorm

      前端开发环境（JetBrains 官网下载即可）

    • CLion

      C/C++ 开发环境（JetBrains 官网下载即可）

    • Eclipse CDT

      C/C++ 开发环境（Eclipse 官网下载即可）
