    一、rpm 命令

    RPM 是 RedHat Package Manager 的缩写，是由 RedHat 公司开发的软件包安装和管理程序，相当于 Windows 里的 exe 文件，使用相应的命令即可在 Linux 中安装所要安装的软件包。除了 rpm 外，Linux 阵营中也还有 deb 软件包管理工具，本人使用的 Deepin 桌面发行版用的就是 deb 软件包管理程序安装软件的。

    二、yum 命令

    Yum 是 Yellow dog updater 的缩写，是一个在 Fedora 和 RedHat 以及 SUSE 中的 Shell 前端软件包管理器，基于 RPM 包管理，能够从指定的服务器自动下载 RPM 包并且安装，可以自动处理依赖性关系，并且一次安装所有依赖的软体包，无须繁琐地一次次下载、安装。yum 提供了查找、安装、删除某一个、一组甚至全部软件包的命令，使用方便快捷。

    rpm、yum 与 apt 的对比：

    特性rpmyumapt
    适用发行版RHEL / CentOS / FedoraRHEL / CentOS / FedoraDebian / Ubuntu / Deepin
    包格式.rpm.rpm.deb

    源仓库配置无（仅管理本地包）/etc/yum.repos.d//etc/apt/sources.list
    典型安装命令rpm -ivh pkg.rpmyum install pkgapt install pkg
    典型卸载命令rpm -e pkgyum remove pkgapt remove pkg
