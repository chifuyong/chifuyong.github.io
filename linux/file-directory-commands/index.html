    Linux 文件目录类常见命令

    chify2019-05-282022-04-27

    一、常用命令速查表

    命令用途常用参数
    pwd显示当前目录-
    ls列出目录内容-a 隐藏文件，-l 详细列表，-lh 人性化大小
    cd切换目录~ 家目录，.. 上级目录，- 上次目录
    mkdir创建目录-p 递归创建
    rmdir删除空目录-
    touch创建空文件-
    cp复制文件/目录-r 递归复制，-f 强制覆盖
    rm删除文件/目录-r 递归，-f 强制
    mv移动/重命名-
    cat查看文件内容-n 显示行号
    head查看文件头部-n 指定行数
    tail查看文件尾部-f 实时跟踪
    echo输出文本-
    ln创建链接-s 软链接

    面对黑压压的 Linux 界面，为让 Linux 系统能完成我们想要达到的功能，熟悉 Linux 的基本命令是必须要做到的，此篇记录的为 Linux 操作文件目录的常用命令。

    二、文件目录类命令

    • 1. pwd（Print working directory）
    • 2. ls（List files）
      ls [参数] 目录名：显示目录下的文件。
    • 3. cd（Change directory）
    • 4. mkdir（Make directory）

    rmdir（Remove directory）

    • 5. touch
      touch 文件名：创建一个空文件（在当前目录下）

    • 6. cp（Copy file）
      cp [参数] 文件名 目录名：复制文件到某个目录下

    使用 -r 参数，将整个文件夹复制到指定目录中去。

    复制中难免出现文件重复的情况，出现此中情况会出现提示，每次都需要输入 y 来确定覆盖文件，如下图：

    使用 \cp -r 命令进行强制覆盖所有需要复制的文件。

    • 7. rm（Remove file）
    • 8. mv（Move file）
      mv oldName newName：用于修改文件名字。
      mv aaa.txt 目录：移动文件到某个目录下。

    mv 目录 目录：移动某个目录到另一个目录下

    • 9. cat（Concatenate）
      cat 文件名：用只读的方式读取文件内容。此命令通常与管道命令一起使用
      -n 可显示行号

    • 10. more
      more 文件：按页显示文件的内容。一次性直接加载文件所有内容，适合查看小文件内容。操作快捷键如下：

    • 11. less
      less 文件：分屏查看文件内容。与 more 命令类似，但是功能比它强大。加载内容是按需加载，适合查看大型文件内容，效率较高。快捷键如下：
    • 12. > 、 >>
      功能：能将打印的内容写入到相应的文件。
      例如：

      flowchart LR
    A[命令输出] -->|">"| B[覆盖写入文件]
    A -->|">>"| C[追加写入文件]
    B --> D[原内容被清除]
    C --> E[原内容保留]
    • 13. echo
      echo "Hello World"：输出 Hello World 到屏幕。
      例如：

    • 14. head
      head 文件：显示文件内容的前10行。
      head -n 5：显示文件内容的前5行，可以是任意行数。
      例如：

    • 15. tail
      tail 文件：查看文件后内容，默认为10行。
      tail -n 5 文件：查看文件后 5 行内容，可以是任意行数。
      tail -f 文件：实时监控此文件的所有更新，有变化则会显示再屏幕上。

    • 16. ln（Link）
      ln -s [文件/目录] 软连接名：类似于 Windows 里的快捷方式，主要存放了链接其他文件的路径。
      注意：使用 pwd 时显示的还是 ln 链接的目录
      例如：

    • 17. history
      history：显示所有命令历史，只显示之前输入的正确的命令，失败的命令不显示。
      history 5：显示最近使用过正确的5个命令，可以是任意数字。
