    Linux 用户管理

    chify2019-03-132022-04-27

    Linux 和 Windows 一样，是一个多用户多任务的操作系统，普通用户都得需要由系统管理员（root）来创建，然后用这个账号才能进入系统。在 Win 下面往往使用者都没有用户组和管理员的概念，使用者并不需要关心这些，但是在 Linux 里面就不一样了，搞清楚用户组和用户的概念是很有必要的，Linux 下用户组和用户关系图如下：

      graph LR
    subgraph 用户管理
        A[root 管理员] --> B[创建用户 useradd]
        A --> C[删除用户 userdel]
        A --> D[修改密码 passwd]
    end

    subgraph 组管理
        E[创建组 groupadd] --> F[用户加入组]
        G[修改用户组 usermod] --> H[删除组 groupdel]
    end

    subgraph 配置文件
        I["/etc/passwd
    用户信息"]
        J["/etc/shadow
    密码信息"]
        K["/etc/group
    组信息"]
    end

    B --> I
    B --> J
    B --> K
    F --> K

    一、关机、重启、用户注销命令

    • 用户首先需要做的就是登录系统，常用的用户登录相关命令简记如下：
    • sync
      把内存中的数据同步到硬盘
      注意：关机或重启时，都应该先 sync 一下，此命令功能是将内存数据写入硬盘，防止数据丢失。

    二、用户管理（root 权限下）命令

    • 增加用户
      useradd [参数] 用户名
      例：useradd -d /home/haha Guan ——表示创建一个名为 Guan，家目录为 /home/haha 的用户。
    • 修改密码
      passwd 用户名
      注意：如需修改自己的密码直接 passwd
    • 删除用户
      userdel [参数] 用户名
      例：userdel Guan ——表示删除用户名为 Guan 的用户，但保留它的家目录。
      例：userdel -r Guan ——表示删除用户名为 Guan 的用户，同时删除其家目录。
    • 查询用户信息
      id 用户名
    • 切换用户
      su 用户名
      普通用户切换到 root 需要密码，反之不用，退出切换使用 exit。

    三、用户组管理命令

    • 增加组
      groupadd 组名
      useradd -g 用户组 用户名 ——表示增加用户的时候就创建一个组，这个用户在这个组里。

    • 删除组
      groupdel 组名

    • 修改用户所在组
      usermod -g 组名 用户名

    • /etc/passwd 文件
      用户的配置文件，记录着用户的各种信息。

    • /etc/shadow 文件
      用于存储 Linux 的密码信息，又称”影子文件”。

    • /etc/group 文件
      组的配置文件，记录 Linux 包含的组信息。
