    chify2022-06-272022-12-29

    首先需要装好 Docker，CentOS 7 安装 Docker 可点击参考此文章

      flowchart LR
    A[拉取 jaspeen/oracle-11g 镜像] --> B[下载 Oracle 11g 安装包]
    B --> C[解压到 /root/oracleinstall]
    C --> D[启动容器并挂载数据卷]
    D --> E[等待安装完成]
    E --> F[进入容器配置用户]
    F --> G[设置密码策略]

    下载 Docker Oracle 镜像

    注：此镜像没有 Oracle 安装包，里面有自动安装数据库的脚本，启动镜像容器时，需要容器卷下有相应的安装包（官网下载），所以大小才 281MB，需要自行下载 Oracle 11g 安装包。

    Oracle 官方安装包获取

    • 下载地址：Oracle 11g 官网下载，下载 linux.x64_11gR2_database_1of2.zip 和 linux.x64_11gR2_database_2of2.zip 两个文件。如下图：

    • 将下载完的文件，使用 xftp 传输到装有 Docker 的 Linux 服务器上，并解压至 /root/oracleinstall，解压后目录如下图：

    总结

    本文记录通过 Docker 快速部署 Oracle 11g 数据库的过程。主要步骤包括：拉取镜像、下载并解压 Oracle 安装包、启动容器并挂载数据卷、进入容器完成用户配置。使用 Docker 部署 Oracle 可以避免复杂的本地安装过程，非常适合开发和测试环境。生产环境需根据实际需求评估是否使用容器化方案。
