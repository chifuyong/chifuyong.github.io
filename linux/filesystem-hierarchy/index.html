    Linux 的目录结构

    chify2019-03-022022-04-28

    在 Linux 的世界里，一切皆是文件。在 Linux 里的文件系统结构和 Windows 中的区别是很大的，所以刚开始接触 Linux 的时候，把 Linux 的目录树搞清楚是非常有必要的！

    一、认识目录树

    Linux 的文件系统是采用层级的树状目录结构，最上一层的目录叫做根目录，记作 /，然后都是在此目录下还有其他相关目录，如下图：

    注：《鸟哥的Linux私房菜》第四版 164 页有更详细的图。

    二、根（/）目录解析

    进入根（/）目录，使用 ls -l 命令（可简写 ll），可获得如下图的结果：

    • /bin：Binary 的缩写，这个目录存放经常用到的命令。
      注：CentOS 7 中，/bin 已被链接到了 /usr/bin，所以这两个目录是一样的

    • /boot：存放了启动 Linux 时的核心文件。

    • /dev：Device 的缩写，Linux 中任何设备与接口设备都是以文件的形式存储在此目录中的，这有点像 Windows 中的设备管理器。例如 /dev/sda 表示第一块硬盘，/dev/tty 表示终端设备。

    • /etc：系统的主要配置文件都放在这里。

    • /home：存放普通用户的主目录，Linux 中每个用户都有一个自己的目录，名字一般都是自己账户名。

    • /lib：此目录放置着在启动时会用到的函数库，以及在 /bin 和 /sbin 下面命令会调用的函数库。

    • lost+found：使用 ext2、ext3、ext4 文件系统才会产生的目录，当文件系统发生错误时，一些遗失的片段会放在这里。

    • /media：也是个设备目录，放在这里的是可以删除的设备。

    • /mnt：过时的目录，如果想要挂载其他的设备，建议可放置在此目录中。

    • /opt：第三方辅助软件放置的目录。比如说安装 Oracle 数据库就可放到这里。

    • /proc：一个虚拟目录，系统内存的映射，访问这个目录可以获取系统信息。存在内存中，不占硬盘空间。

    • /root：系统管理员目录，也就是 root 超级管理的主目录。

    • /run：存放系统运行时产生的临时数据，如 PID 文件、socket 文件等。系统重启后该目录内容会被清空。

    • /sbin（/usr/sbin、/usr/local/sbin）：Super Binary 的意思，系统管理员（root）才能使用到的命令。

    • /selinux：Security-enhanced Linux 缩写，是个安全子系统，能控制程序只访问特定文件。

    • /srv：service 的缩写，此目录存放一些服务启动之后需要提取的数据。

    • /sys：与 /proc 类似，主要记录内核与系统硬件信息，存在于内存，不占用硬盘空间。

    • /tmp：一般用户或是正在执行的程序暂时放置文件的地方。

    • /usr：Unix Software Resource 的缩写，也就是 Unix 操作系统软件资源所放置的位置，不是用户数据。FHS 建议软件开发者，应该将他们的数据合理的放置到这个目录下的子目录。

    • /var：/var 是系统运行时会渐渐占用硬盘容量。因为 /var 主要针对经常变动的文件，包括缓存、日志文件及某些软件运行所产生的文件，例如 Oracle 数据库文件。

    三、小结

    Linux 的目录结构遵循 FHS（Filesystem Hierarchy Standard） 标准，理解各目录的用途对于日常运维和开发至关重要。简单记住以下原则：

    目录用途
    /bin、/sbin系统命令
    /etc配置文件
    /home、/root用户主目录
    /var可变数据（日志、缓存）
    /tmp临时文件
    /proc、/sys、/run虚拟文件系统
