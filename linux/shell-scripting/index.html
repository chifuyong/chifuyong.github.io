    二、变量

    Shell 中的变量可以分为两类：系统变量和用户自定义变量。

    • 系统变量：由操作系统内置，例如 $HOME、$PATH、$USER。
    • 用户自定义变量：由脚本编写者自己定义。

    可以使用 set 命令查看当前环境中的所有系统变量。

    • 变量：系统变量、用户自定义变量、位置参数变量和预定义变量
